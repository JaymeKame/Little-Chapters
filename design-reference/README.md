# Little Chapters — Approved UI Reference

The PNG files in this directory are the visual source of truth for the current UI redesign.

The objective is to reproduce these designs as closely as practical in the existing application while preserving existing product functionality.

## Rules

- Treat these images as the primary visual reference.
- Do not redesign them based on personal preference.
- Do not change backend or feature architecture to achieve visual fidelity.
- Preserve existing application behavior unless explicitly instructed otherwise.
- Do not modify unrelated routes.
- Work one screen at a time.
- Compare the implemented page against its corresponding reference image before declaring the task complete.
- Existing feature work from other engineers must not be removed or rewritten.
